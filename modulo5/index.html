A Tradução Monetária do Progresso: VA, CR e VP

Para a diretoria e comitês de finanças, dizer que o projeto está "80% concluído" com base em sentimento não significa nada. O método EVA (Earned Value Analysis) traduz o progresso físico em dinheiro real através de três variáveis matemáticas fundamentais.

OS TRÊS PILARES FINANCEIROS (CLIQUE PARA EXPANDIR OS CONCEITOS):

01 // VP (VALOR PLANEJADO)

A meta orçamentária acumulada prevista na Linha de Base para a data atual.

02 // CR (CUSTO REAL)

O extrato contábil das saídas efetivas de caixa e pagamentos realizados.

EXPANDIR 🔍

03 // VA (VALOR AGREGADO)

O valor orçado do trabalho entregue e validado pela qualidade. O coração do EVA.

Desafio de Fixação: Análise Clínica do Cenário EVA

🎯 PERGUNTA CRÍTICA DE CONTROLADORIA:
Um GP gerencia uma entrega com orçamento total de R$ 200 mil. Na data de hoje, o planejamento indicava que R$ 100 mil deveriam ter sido executados (VP). O relatório de lançamentos financeiros mostra que R$ 120 mil foram gastos (CR). No entanto, a medição física e de qualidade atesta que apenas R$ 80 mil de entregáveis foram concluídos (VA). Qual a análise clínica do cenário?
[A] O projeto está em excelente situação, pois gastar R$ 120 mil significa que a equipe técnica está trabalhando em velocidade acelerada.
[B] O projeto está adiantado em relação ao cronograma, uma vez que o Custo Real ultrapassou o Valor Planejado para o período.
[C] O GP deve utilizar a reserva gerencial para reajustar o VP para R$ 120 mil, eliminando o desvio dos relatórios da controladoria de forma automática.
[D] O projeto apresenta um cenário crítico de ineficiência: está atrasado em relação às metas planejadas e operando com estouro de custos, tendo gerado apenas R$ 80 mil de valor real para um gasto de R$ 120 mil.
[E] O cenário prova que o modelo tradicional faliu, devendo o projeto ser migrado para tarefas diárias sem acompanhamento de indicadores orçamentários.

// PÍLULA 5.2 • EFICIÊNCIA DE CUSTOS E PRAZOS

Dominando o CPI (Custo) e o SPI (Prazo)

A regra de ouro da controladoria executiva é simples: 1.0 é a paridade exata com o plano. Acima de 1.0 indica eficiência superior (gastando menos ou entregando mais rápido); abaixo de 1.0 aponta perda de rentabilidade ou atraso físico.

AS DUAS FÓRMULAS DE PERFORMANCE (CLIQUE PARA VER OS DETALHES DE CÁLCULO):

01 // CPI = VA / CR (CUSTO)

Mede a rentabilidade financeira. Se CPI > 1.0, o projeto está economizando; se CPI < 1.0, está estourando o custo.

EXPANDIR FÓRMULA 🔍

02 // SPI = VA / VP (PRAZO)

Mede a velocidade física da entrega. Se SPI > 1.0, o cronograma está adiantado; se SPI < 1.0, está atrasado.

EXPANDIR FÓRMULA 🔍

Desafio de Fixação: Interpretação de Índices Executivos

🎯 PERGUNTA CRÍTICA DE COMITÊ EXECUTIVO:
Em um comitê de governança mensal com a alta diretoria, o GP apresenta um relatório indicando que o projeto possui um CPI de 1.15 e um SPI de 0.82. Qual é a interpretação analítica exata que o GP deve expor aos executivos?
[A] O projeto está economizando orçamento (eficiência financeira de 15% acima da meta), porém apresenta uma tendência de atraso temporal relevante, tendo executado apenas 82% do cronograma planejado para o período.
[B] O projeto está operando com custos acima do planejado, mas as entregas físicas estão adiantadas em relação às metas do cronograma.
[C] A equipe técnica está desperdiçando recursos financeiros, embora o ritmo temporal de cumprimento das tarefas esteja perfeito.
[D] Os indicadores provam que o projeto deve ser paralisado imediatamente, visto que qualquer índice diferente de 1.0 exprime erro grave de engenharia.
[E] O GP deve alterar os dados de Valor Agregado manualmente até que ambos os índices atinjam o patamar de 1.0 antes de enviar o report ao PMO.
// PÍLULA 5.3 • MODELAGEM PREDITIVA

Substituindo Suposições por Modelagem: O EAC

O real valor de um GP sênior está em projetar o futuro com exatidão matemática. A métrica EAC (Estimate at Completion), ou Estimativa no Término, calcula cientificamente qual será o custo final real do projeto caso o ritmo atual de desempenho financeiro se mantenha.

AS EXPRESSÕES DE PROJEÇÃO ECONÔMICA (CLIQUE PARA VER O CRITÉRIO):

01 // EAC = CR + (BAC - VA)

Desvios atípicos. O trabalho restante será realizado na taxa orçada original sem repetir falhas passadas.

EXPANDIR CRITÉRIO 🔍

02 // EAC = BAC / CPI

Performance histórica contínua. Projeta o custo final mantendo o ritmo de eficiência atual até o encerramento.

EXPANDIR CRITÉRIO 🔍
// AVALIAÇÃO DE FIXAÇÃO • PÍLULA 5.3

Desafio de Fixação: Cálculo Estatístico de EAC

🎯 PERGUNTA CRÍTICA DE PROJEÇÃO FINANCEIRA:
Um projeto estratégico possui orçamento total homologado (BAC) de R$ 500 mil. Devido a problemas estruturais com fornecedores na fase intermediária, o CPI atual do projeto estabilizou em 0.80. A diretoria exige saber qual será o real custo final previsto se o ritmo operacional continuar o mesmo. Qual é a projeção matemática exata de EAC a ser reportada?
[A] R$ 500.000,00, pois as variações de percurso são absorvidas automaticamente pelos analistas sem alterar a previsão final de desembolso.
[B] R$ 400.000,00, multiplicando o orçamento total pelo índice de desempenho para demonstrar redução de escopo.
[C] R$ 515.000,00, adicionando a reserva de contingência padrão de riscos mapeados de forma linear ao valor original.
[D] R$ 0,00, uma vez que previsões financeiras de longo prazo são impossíveis no ambiente de transformação corporativa moderno.
[E] R$ 625.000,00, calculando estatisticamente o orçamento total dividido pela eficiência real acumulada de 0.80 (EAC = 500.000 / 0.80).
